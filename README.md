# ReYdeX Game Booster

ReYdeX Game Booster is a premium utility application for Android designed to enhance your mobile gaming experience. Built with a sleek, dark futuristic UI, it offers game management, quick performance boosts, device monitoring, and system optimization controls directly from the app or an optional floating overlay.

## Features (In Development)

*   **Dashboard & Monitoring:** View real-time device stats including FPS, CPU, RAM, battery, and temperature (where available). Features a Quick Boost button and a gaming session timer.
*   **Game Library & Profiles:** Easily manage installed games, select games manually, configure game-specific performance profiles, and launch games directly from the app.
*   **System Optimization Controls:** Toggle system settings to minimize distractions and optimize hardware. Includes controls for Android Game Mode (if supported), Do Not Disturb, screen brightness, rotation lock, keep screen on, and network/Wi-Fi shortcuts.
*   **Performance Overlay:** An optional floating panel requiring overlay permissions to monitor stats and access quick controls during gameplay.
*   **Permission Center:** A centralized hub to manage and request necessary Android permissions (like overlay and DND), indicating clearly when advanced permissions are needed.

*Note: This app strictly utilizes legitimate Android APIs and supported functionality. It does not employ placebo optimizations.*

## Tech Stack
*   **Framework:** Flutter
*   **Language:** Dart (UI), Kotlin (Platform Channels & Native Logic)
*   **Platform:** Android (Primary focus for system controls)

## Setup and Run

1. Ensure you have the Flutter SDK installed and an Android device or emulator running.
2. Clone this repository.
3. Run `flutter pub get` to install dependencies.
4. Run `flutter run` to build and deploy the app to your device.
